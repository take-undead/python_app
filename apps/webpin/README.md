# webpin

ESP32（TTGO T-Display）から WebSocket でピン情報を受け取り、
リアルタイムにグラフ表示しながら CSV に記録するアプリ。

```powershell
python apps/webpin/main.py
```

## 接続先

マイコン側は WiFi 接続後に `ws://<IP>/ws` で待ち受ける。

ローカルネットワーク前提なので、**`192.168.` は固定**で、残りの 2 つだけを
入力する（各 0〜255）。

```
接続先: 192.168.[ 1 ].[ 132 ]   → ws://192.168.1.132/ws
```

既定は `1` `132`（`config.h` の `STATIC_IP`）。つなぐネットワークが 192.168.2.x
なら 3 つ目を `2` にする。空欄や範囲外はエラーダイアログで知らせる。
接続が切れた場合は 3 秒ごとに自動で再接続する。

## 受信する内容

マイコンは約 200ms 間隔（`WS_UPDATE_INTERVAL_MS`）で `state` メッセージを送る。
これを次の名前の系列に展開して、グラフと CSV の列に使う。

| 系列名 | 内容 |
| --- | --- |
| `AIN1(GP36).raw` 〜 `AIN4(GP33).raw` | ADC の生値（0〜4095） |
| `AIN1(GP36).volt` 〜 `AIN4(GP33).volt` | 3.3V 換算した電圧 |
| `DIN1(GP37)` / `DIN2(GP38)` | デジタル入力（0 / 1） |
| `DOUT1` 〜 `DOUT5` | デジタル出力の状態（0 / 1） |
| `audio.playing` / `audio.freq` / `audio.volume` | I2S オーディオの状態 |

`ack` など `state` 以外のメッセージは記録しない。

## 操作

- **接続 / 切断** — 受信の開始と停止。
- **記録開始 / 記録停止** — CSV への記録。保存先は既定で `apps/webpin/logs/`。
- **クリア** — グラフと最新値の履歴を消す（記録中のファイルはそのまま）。
- **表示範囲** — グラフの横軸を直近 10 秒〜全期間で切り替える（全グラフ共通）。
- **右のピン一覧** — 系列ごとに、どのグラフに出すかを `―`（非表示）/ `1` / `2` / `3`
  から選ぶ。最新値も表示する。
- **出力**（`DOUT*` の行だけ） — チェックでマイコンの出力を ON / OFF する。

## DOUT の ON/OFF

`DOUT1` 〜 `DOUT5` の行に付く「出力」チェックで、マイコンの digitalWrite を
切り替える。押すと次のコマンドを送る。

```json
{"type":"set_dout","pin":17,"state":true}
```

チェックの見た目は**マイコンが返してくる `state` に追従する**。送信できても
実際に切り替わらなければチェックは戻り、マイコン側や他のクライアントが変えた
場合もこちらに反映される。未接続のときは押せない（押した場合はエラーを表示して
元に戻す）。

## グラフ

グラフは縦に 3 面あり、桁の違う系列を別々の軸で見られる。系列を 1 つも
割り当てていない面は畳まれ、残りの面が高さを分け合う。

初期の割り当ては系列の種類で決まる（あとから自由に変更できる）。

| 系列 | 初期の割り当て |
| --- | --- |
| `*.volt` | グラフ 1 |
| `DIN*` / `DOUT*` | グラフ 2 |
| その他（`audio.*` など） | グラフ 3 |
| `*.raw` | 非表示（0〜4095 で桁が違うため） |

各グラフの見出しで**縦軸の縮尺**を指定できる。

- **自動**（既定） — 表示中の系列の最小・最大に合わせる。
- **自動を外す** — 最小・最大を**数値入力とバー**の両方で調整できる
  （例: `0` 〜 `3.3` で電圧を常に同じ縮尺で見る）。外した時点の範囲が
  初期値として入り、バーはその上下に同じ幅だけ広げた範囲を動かせる。
  バーの範囲を超える値は数値で入れれば、バーの目盛りごと広がる。
  範囲からはみ出した線は枠内に丸めて描く。

横軸（表示範囲）は全グラフ共通、縦軸はグラフごとに独立している。

## 時刻

マイコンは時刻を送ってこないため、**受信した時点の PC の時計**を使う。
グラフの横軸の目盛り（`15:11:41`）も CSV の `時刻` 列もこれが元になる。

## CSV の形式

`時刻, 経過秒, <系列名...>` の順。Excel で開いても日本語が化けないよう
BOM 付き UTF-8（`utf-8-sig`）で書き出す。

```csv
時刻,経過秒,AIN1(GP36).raw,AIN1(GP36).volt,...,DIN1(GP37),...
2026-08-17 11:11:44.283,0.000,2048,1.65,...,0,...
```

列は記録を開始した最初の 1 件で確定する。途中で新しいピンが現れた場合、
その列は記録されず、記録停止時に警告を出す。

## 構成

| ファイル | 役割 |
| --- | --- |
| `logic/protocol.py` | 受信 JSON → 系列名と値の辞書。**書式が変わったらここを直す** |
| `logic/ws_client.py` | WebSocket 受信スレッドと自動再接続 |
| `logic/series.py` | グラフ用の時系列バッファ（既定 3000 点／系列） |
| `logic/recorder.py` | CSV への書き出し |
| `ui/chart.py` | `tk.Canvas` に直接描く折れ線グラフ |
| `ui/main_window.py` | 画面全体と受信の取り込み |

## 依存

`websocket-client`（リポジトリ直下の `requirements.txt` に含む）。
グラフは matplotlib を使わず `tk.Canvas` に直接描いている。
